# Reload

Description
Reload is a clapping game of unknown origins. In fact, I am not even sure if "Reload" even is its real name.
As far as I know, the Philippines has Reload players, and there is also a similar, if not the exact same, game in Canada.
In Canada, Reload has a different name apparently.
Unfortunately, the person who told me that does not remember what the name was.

History
Back when I was in grade 2, the game became popular and it remained popular among my batch until the Covid pandemic struck.

Anyways, this is my recreation of the game. I no longer remember the exact rules but I'll try my best to preserve the original as much as possible.
